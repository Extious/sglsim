## Interpretation

This figure is intentionally more conservative than the earlier policy-model
row. It measures end-to-end replay request latency, so the recovery improvement
is diluted by normal serving time in the current low-concurrency smoke
workload. It is still useful because it ties Fig. 8 to actual HTTP replay rows
and hard scheduler kill/restart rather than pure post-trace arithmetic.
