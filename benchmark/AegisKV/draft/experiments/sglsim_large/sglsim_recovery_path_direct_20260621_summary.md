## Interpretation

The current Fig. 10 AegisKV row is now a direct serving-path measurement across
three regimes that deliberately exercise different lower-envelope choices. The
long-prefix workload has both HostBackup and peer GPUReplica directory hits but
selects Host H2D. The short peer workload selects GPUReplica for the protected
tail and recomputes the suffix. The short non-peer workload shows recompute can
beat Host H2D when the fixed restore cost is not worth paying.

This is still not final physical KV-copy evidence. The replay rows materialize
target-rank device-cache metadata and sleep for the selected restore plan, but
real CUDA tensor KV movement remains future validation.
